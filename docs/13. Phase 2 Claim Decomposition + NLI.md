# Phase 2 — Claim Decomposition + NLI Verification

**Date:** 22 Jul 2026
**Status:** ✅ Implemented (pending eval)

---

## Overview

Phase 2 adds semantic claim verification via Natural Language Inference (NLI) on top of Phase 1's structured output. Instead of only checking verbatim quotes, NLI checks whether each atomic claim is *semantically entailed* by the source chunks.

## Architecture

```
Structured answer (Phase 1)
  → decompose_claims() — LLM-based atomic claim decomposition
    → verify_claims_nli() — DeBERTa-v3-large batch NLI
      → aggregate_verdicts() — pass/fail at >50% unsupported
        → nli_verdicts + nli_summary attached to response
```

## Files

### `src/nli.py` (NEW)
| Component | Detail |
|-----------|--------|
| `NLIClient` class | Wraps DeBERTa-v3-large via `transformers.pipeline("text-classification")` |
| `_load()` | Lazy-load model on first `verify()` call |
| `verify(claim, chunks, threshold)` | Single claim → verdict + entailment score |
| `verify_batch(claims, chunks, threshold)` | Batch version for multiple claims |
| `unload()` | Release model + GC collect |
| Model | `MoritzLaurer/DeBERTa-v3-large-mnli-fever-anli-ling-wanli` (~1.5GB) |
| Threshold | Default 0.72 (from solana.garden production benchmark) |

### `src/verifier.py` (EDITED)
| Function | Detail |
|----------|--------|
| `decompose_claims(answer_text, llm)` | LLM-based → atomic claims JSON |
| `DECOMPOSITION_SYSTEM_PROMPT` | Prompt template for claim decomposition |
| `verify_claims_nli(claims, chunks, nli_client, threshold)` | Verifies each claim against top-3 chunks |
| `aggregate_verdicts(verdicts)` | Counts supported/unsupported, pass if <=50% unsupported |

### `src/rag.py` (EDITED)
- After structured output success → if `config.nli_enabled`:
  1. `decompose_claims(parsed.answer, llm)`
  2. `verify_claims_nli(sub_claims, results, nli_client, threshold)`
  3. `aggregate_verdicts(nli_verdicts)`
  4. Log warning if overall="fail"
  5. Attach `nli_verdicts` + `nli_summary` to response
