# Product development handoff

Updated: 2026-11-09

## Product

Build one product for independent financial analysts and small teams researching US companies. It answers why a metric changed in SEC 10-K and 10-Q filings. The website is an invite-only demo and a portfolio case study.

Start with reviewed restaurant and retail examples. Allow free questions only for companies and filing periods in a verified index. Report a cause only when a filing explicitly connects it to the metric. Otherwise show related passages and state that the cause is unconfirmed. Use English for the interface and case study.

Do not set prices yet. In invited analyst sessions, record source relevance, trust after checking filings, time saved, intent to reuse, and misleading answers.
