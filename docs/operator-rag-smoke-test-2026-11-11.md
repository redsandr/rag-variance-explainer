## Next decisions and release checks

1. **Retrieval first:** Build deterministic retrieval-only regressions for two tickers/two distinct report dates, one ticker/one date, absent period, and ambiguous/no ticker. Check per-company and per-period coverage *before* reranking/top-k truncation. Do not guess a ticker/date mapping when question semantics are ambiguous; return a clarification or missing-evidence state. Check whether two independent filtered queries per (ticker, period) or another constrained plan is justified by broader examples, not just CMG-JNJ.
2. **Quote mismatch:** Capture the structured model output in a redacted test fixture (without secrets or unapproved personal data). Test citation index, quote text, candidate passages, and whether a quote is unique across sources. Preserve fail-closed behavior; distinguish incorrectly numbered but otherwise exact quotes from invented ones. Never relabel a citation automatically just to make one response pass.
3. **Financial claims:** Review displayed answer vs structured claims and log the exact statement-to-quote mapping. Add human-reviewed cases for nested causal components, percentage-point differences, arithmetic, conflicting periods, and unsupported causal claims across companies. Do not calibrate an NLI threshold against the current 16 agent-drafted cases.
4. **Speed:** Record comparable server runs with effective GPU offload/VRAM, prompt size, decode token count, cache state, concurrent workload and per-run completion timings; no cause for CMG-2's ~6 t/s is established from its four progressive lines alone. The user runs any model inference.

## Research checked for decisions (not proof of this app's correctness)

- [Chroma filtering documentation](https://cookbook.chromadb.dev/core/filters/) documents `where` filters in `Collection.query` and `Collection.get`, including metadata conjunctions. This supports investigating per-company/per-period filtering; it does **not** prescribe how to parse a multi-company question.
- [FEVER (Thorne et al., 2018)](https://aclanthology.org/N18-1074/) defines supported/refuted/not-enough-info evidence annotations; its Wikipedia benchmark is not a financial-domain validation of this NLI model.
- [FActScore (Min et al., 2023)](https://arxiv.org/abs/2305.14251) motivates atomic-fact evaluation and highlights mixed supported/unsupported content; its biography results do not transfer to SEC analysis.
- Primary originals for spot checks: [CMG Q2 2024 10-Q](https://www.sec.gov/Archives/edgar/data/1058090/000105809024000032/cmg-20240630.htm), [WMT 2026 10-Q](https://www.sec.gov/Archives/edgar/data/104169/000010416926000102/wmt-20260430.htm), [JNJ 2026 10-Q](https://www.sec.gov/Archives/edgar/data/200406/000020040626000087/jnj-20260329.htm).
