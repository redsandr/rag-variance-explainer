## Release rule

Do not describe the project as production ready while any clean-clone, index, end-to-end answer, or faithfulness gate is open. The application is a useful local research tool when users can inspect its sources and understand its limits. A future production deployment needs authentication, resource limits, operational monitoring, and a supported data refresh process.
